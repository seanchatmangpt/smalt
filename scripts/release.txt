## Port overridability (still-current reference)

`Smalt.Application` reads `Application.get_env(:smalt, :arm_port, 9443)` and
`:egress_port` (default 8443). In a release, override via a `rel/env.sh.e`
snippet:

```elixir
# rel/env.sh.e
import Config
config :smalt,
  arm_port: String.to_integer(System.get_env("SMALT_ARM_PORT") || "9443"),
  egress_port: String.to_integer(System.get_env("SMALT_EGRESS_PORT") || "8443")
```

Until that file lands, `scripts/release.sh` verifies boot against the default
ports (doctor already gates that 9443/8443/5672 are free).
