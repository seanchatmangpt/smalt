\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Contemporary distributed cloud engineering suffers from an acute epistemological crisis: the pervasive substitution of live, stateful substrate execution with interaction mocks, synthetic stubs, and unverified assertion claims. When verification is decoupled from the physical socket layer, formal soundness collapses into tautology---a phenomenon we formalize as the \emph{Chicago Gap}. In high-assurance legal enterprise environments, such as the Kirkland \& Ellis LLP Courtroom AI platform, this gap introduces unacceptable exposure across multi-tenant isolation boundaries, cryptographic secret lifecycles, cold-storage compliance archives (CRMH), and Security Information and Event Management (SIEM) attribution pipelines.

This dissertation resolves the Chicago Gap by establishing a unified mathematical, geometric, algebraic, and empirical framework for zero-cloud sovereign infrastructure. At the foundation of our treatise is the \textbf{Chatman Equation}:
\[
\Act = \mu(\Oadm), \qquad \Rec = \mathrm{receipt}(\Act), \qquad \Oadm = \mathbf{a}_J(\Oraw) = \Oraw_{\mathrm{aligned}} \cap \Oraw_{\mathrm{grounded}} \cap \Oraw_{\mathrm{bounded}} \cap \Oraw_{\mathrm{admitted}}
\]
We formalize raw observations $\Oraw$ as presheaves over a site of execution contexts $(\mathcal{C}, J)$ and prove that the admission gate $\mathbf{a}_J$ is an idempotent left-exact sheafification functor into the Grothendieck topos of admitted truths $\mathrm{Sh}(\mathcal{C}, J)$. \section{The Epistemic Crisis of Distributed Cloud Verification}
Modern enterprise software engineering operates atop deeply stratified cloud abstractions. A single user interaction in a legal intelligence portal traverses browser DOM state, React server components, reverse proxies, SAML 2.0 identity assertions, Infrastructure-as-Code (IaC) state graphs, systems-level transport membranes, and distributed key-value or relational storage engines. When engineering teams attempt to verify such systems locally or in continuous integration (CI), they overwhelmingly resort to \emph{London-school interaction mocking}: replacing real network sockets, authentication authorities, and storage engines with in-memory test doubles (\texttt{Mock}, \texttt{MagicMock}, \texttt{gomock}, \texttt{testify/mock}, or synthetic HTTP interceptors).

We prove that interaction mocking introduces a fatal mathematical pathology: it replaces the evaluation of the true system morphism $f: X \to Y$ with an evaluation of an ungrounded endomorphism $f_{\mathrm{mock}}: X_{\mathrm{stub}} \to X_{\mathrm{stub}}$ whose codomain is isomorphic to the test author's own prior assumptions.

\begin{definition}[The Chicago Gap]
Let $\mathcal{S} = P_1 \times P_2 \times \dots \times P_k$ be a composite multi-plane software architecture where each plane $P_i$ communicates with $P_{i+1}$ over a physical operating system socket interface $\Sigma_{i,i+1}$ (TCP loopback or Unix Domain Socket). Let $\mathcal{T}$ be a test suite intending to verify a global safety or compliance invariant $\Phi(\mathcal{S})$. The \textbf{Chicago Gap} $\Delta_{\mathrm{Chicago}}(\mathcal{T}, \mathcal{S})$ is defined as the measure of the kernel of the projection from mocked transitions to socket-grounded transitions:
\begin{equation}
\Delta_{\mathrm{Chicago}}(\mathcal{T}, \mathcal{S}) \coloneqq 1 - \frac{\mu_{\mathrm{Lebesgue}}\!\left(\left\{ \omega \in \Omega_{\mathcal{T}} \;\middle|\; \forall i \in \{1,\dots,k-1\},\; \mathrm{Flux}_{\Sigma_{i,i+1}}(\omega) > 0 \land \mathrm{Mocks}(\omega) = \emptyset \right\}\right)}{\mu_{\mathrm{Lebesgue}}(\Omega_{\mathcal{T}})}
\end{equation}
where $\mathrm{Flux}_{\Sigma_{i,i+1}}(\omega)$ denotes the byte flux across the kernel socket buffer between plane $P_i$ and plane $P_{i+1}$ during test execution $\omega$. A verification architecture closes the Chicago Gap if and only if $\Delta_{\mathrm{Chicago}}(\mathcal{T}, \mathcal{S}) = 0$.
\end{definition}

During the October 30, 2026 Courtroom Engineering Standup (attended by Sean Chatman, Dilip Shekhar, and Anirudh D), seven foundational operational requirements were established for the Kirkland \& Ellis LLP deployment:
\begin{enumerate}[label=\textbf{REQ-\arabic*:}]
    \item \textbf{Reusable Terraform Base Templates \& Client Variables}: Infrastructure provisioning must use a unified Terraform base module parameterized by client-specific variable files (\texttt{kirkland.tfvars}) rather than bespoke, copy-pasted per-client pipelines containing hardcoded tokens.
    \item \textbf{Consolidated Single Container App Architecture}: Separate frontend and backend container instances must be consolidated into a single Azure Container App instance (\texttt{ca-kirkland-consolidated}) per case or admin structure to eliminate inter-container drift and reduce attack surface.
    \item \textbf{Case-Level Virtual Network \& Resource Isolation}: Customer cases (matters) must be isolated at the resource and virtual network boundary (\texttt{matter/matter-9042}) rather than sharing multi-tenant global state.
    \item \textbf{CRMH 14-Day Cold Archive Lifecycle}: Case Recording and Matter History (CRMH) exports must be written as Parquet blobs matching the canonical naming regular expression \texttt{\^{}crmh\_kirkland\_.*\\.parquet\$} with an enforced minimum retention lifecycle of $T_{\mathrm{ret}} \ge 14\text{ days}$.
    \item \textbf{SIEM Event Hub Matter Attribution}: Every security and audit event streamed to Azure Event Hubs / Cribl SIEM must preserve explicit matter attribution (\texttt{x-ms-matter-id: KIRK-2026-9042}) and environment classification (\texttt{environment: dev01}).
    \item \textbf{Cryptographic Turnstile Mediation}: Every secret retrieval from Azure Key Vault and every state mutation across the sovereign membrane must be mediated by a cryptographic turnstile yielding a verifiable BLAKE3-256 digest (\texttt{x-smalt-receipt-turnstile}).
    \item \textbf{Hard Egress Refusal of Cloud Metadata Services}: Any attempt by application or provider code to probe the cloud Instance Metadata Service (\texttt{169.254.169.254}, IPv4-mapped IPv6 \texttt{::ffff:169.254.169.254}, or unspecified \texttt{0.0.0.0}) must be mechanically trapped at the socket dialer and refused with HTTP 403.
\end{enumerate}

\section{Sheaf-Theoretic Formulation of Observations $\Oraw$ and Admission $\Oadm$}
To reason rigorously about what an autonomous agent or verification court may admit as truth, we construct a categorical epistemology based on Grothendieck topoi.

\begin{definition}[Category of Execution Contexts $\mathcal{C}$]
Let $\mathcal{C}$ be a small category whose objects $U, V, W \in \mathrm{Ob}(\mathcal{C})$ are bounded execution scopes (characterized by a repository path scope, a Git commit tree SHA $h \in \Sigma^{40}$, a toolchain identity, and an environment vector), and whose morphisms $\iota: V \hookrightarrow U$ are scope refinements (restriction maps).
\end{definition}

\begin{definition}[Observation Presheaf $\Oraw$]
A raw observation is a contravariant functor (presheaf) $\Oraw: \mathcal{C}^{\mathrm{op}} \to \mathbf{Set}$. Elements $s \in \Oraw(U)$ over a context $U$ represent unverified claims: README statements, commit messages, surveyor subagent reports, LLM-generated plans, unexecuted code diffs, or literal status strings (\texttt{"PASS"}).
\end{definition}

Because raw observations $\Oraw(U)$ are partial, stale, and noisy (empirically measured across 455 single-agent survey claims to exhibit a $35.8\%$ overall error rate and a $46.5\%$ error rate on standing/receipt claims), applying a manufacturing functor directly to $\Oraw$ constitutes a foundational type error.

\begin{definition}[Grothendieck Topology of Lawful Admission $J$]
We equip $\mathcal{C}$ with a Grothendieck topology $J$ assigning to each context $U \in \mathrm{Ob}(\mathcal{C})$ a collection of covering sieves $S \in J(U)$ corresponding to the four admission sub-predicates:
\begin{align}
\mathcal{P}_{\mathrm{aligned}}(s, U) &\iff \mathrm{SubjectSHA}(s) = \mathrm{HEAD}(U) \land \mathrm{WorktreeCount}(U) = 1 \\
\mathcal{P}_{\mathrm{grounded}}(s, U) &\iff \exists\, \text{kernel process execution } \pi \text{ on } U \text{ with exit code } 0 \text{ and } \mathrm{stdout}(\pi) \vdash s \\
\mathcal{P}_{\mathrm{bounded}}(s, U) &\iff \mathrm{Cost}(s) \le B_{\mathrm{max}} \land \mathrm{Authority}(s) \preceq \alpha_{\mathrm{ceiling}}(U) \\
\mathcal{P}_{\mathrm{admitted}}(s, U) &\iff \forall\,\text{adversarial mutants } m \in \mathfrak{M}(s),\; \mathrm{Gate}_U(m) = \mathrm{REFUSED}
\end{align}
\end{definition}

\begin{theorem}[Sheafification as the Admission Functor $\Oadm = \mathbf{a}_J(\Oraw)$]
Let $\widehat{\mathcal{C}} = [\mathcal{C}^{\mathrm{op}}, \mathbf{Set}]$ be the category of raw observation presheaves, and let $\mathrm{Sh}(\mathcal{C}, J)$ be the full subcategory of $J$-sheaves (admitted observations). The inclusion functor $i: \mathrm{Sh}(\mathcal{C}, J) \hookrightarrow \widehat{\mathcal{C}}$ admits a left-exact left adjoint $\mathbf{a}_J: \widehat{\mathcal{C}} \to \mathrm{Sh}(\mathcal{C}, J)$ constructed via the two-step Plus-construction $\mathbf{a}_J(\Oraw) = (\Oraw^+)^+$, where:
\begin{equation}
\Oraw^+(U) = \varinjlim_{S \in J(U)^{\mathrm{op}}} \mathrm{Hom}_{\widehat{\mathcal{C}}}(S, \Oraw)
\end{equation}
We define the space of admitted observations as $\Oadm \coloneqq \mathbf{a}_J(\Oraw)$. By adjunction, for any sheaf $\mathcal{F} \in \mathrm{Sh}(\mathcal{C}, J)$, there is a natural bijection:
\begin{equation}
\mathrm{Hom}_{\mathrm{Sh}(\mathcal{C}, J)}(\Oadm, \mathcal{F}) \cong \mathrm{Hom}_{\widehat{\mathcal{C}}}(\Oraw, i(\mathcal{F}))
\end{equation}
Furthermore, $\mathbf{a}_J$ is idempotent ($\mathbf{a}_J(\Oadm) \cong \Oadm$) and preserves finite limits (intersections):
\begin{equation}
\Oadm = \mathbf{a}_J(\Oraw) = \Oraw_{\mathrm{aligned}} \cap \Oraw_{\mathrm{grounded}} \cap \Oraw_{\mathrm{bounded}} \cap \Oraw_{\mathrm{admitted}}
\end{equation}
\end{theorem}
\begin{proof}
To verify that $\Oadm = (\Oraw^+)^+$ satisfies the sheaf gluing axiom, let $\{ \iota_\alpha: U_\alpha \to U \}_{\alpha \in I}$ be a covering family in $J(U)$, and let $\{ s_\alpha \in \Oadm(U_\alpha) \}_{\alpha \in I}$ be a matching family such that for all $\alpha, \beta \in I$, $s_\alpha|_{U_\alpha \times_U U_\beta} = s_\beta|_{U_\alpha \times_U U_\beta}$. Because each $s_\alpha$ satisfies the four local predicates $\mathcal{P}_{\mathrm{aligned}}$, $\mathcal{P}_{\mathrm{grounded}}$, $\mathcal{P}_{\mathrm{bounded}}$, and $\mathcal{P}_{\mathrm{admitted}}$ on $U_\alpha$, and because git tree hashes, exit codes, authority ceilings, and mutation refusals are local properties that agree on fiber products $U_\alpha \times_U U_\beta$, the colimit over the refined sieve $S = \langle \iota_\alpha \rangle$ contains a unique global section $s \in \Oadm(U)$ restricting to $s_\alpha$ on each $U_\alpha$. Left-exactness follows immediately from the fact that filtered colimits over $J(U)^{\mathrm{op}}$ commute with finite limits in $\mathbf{Set}$.
\end{proof}

// MaxFrameBytes bounds a single framed message (POSH-008 bounded buffers).
const MaxFrameBytes = 4 << 20

// maxPooledFrameBytes caps the maximum slice capacity returned to framePool
// (64 KiB) so anomalous multi-megabyte burst frames are reclaimed by GC
// instead of permanently pinning pool memory across P's.
const maxPooledFrameBytes = 64 << 10

// frameBuf wraps a reusable byte slice in a pointer struct so sync.Pool.Put
// stores a pointer directly in its interface slot without a 24-byte heap
// allocation (runtime.convTslice).
type frameBuf struct {
	b []byte
}

// connState holds per-UDS-connection framing scratch allocated once at
// connection accept time so per-frame reads and writes do not allocate
// 4-byte length header buffers on the heap. bufs is the scatter-gather write
// vector: net.Buffers.WriteTo CONSUMES the slice, so it is rebuilt in place
// per frame via append on the retained capacity (zero slice allocations).
type connState struct {
	hdr  [4]byte
	br   *bufio.Reader
	bufs net.Buffers
}

var framePool = sync.Pool{
	New: func() any {
		return &frameBuf{b: make([]byte, 4096)}
	},
}

func getFrameBuf(n uint32) ([]byte, *frameBuf) {
	if n <= maxPooledFrameBytes {
		fb := framePool.Get().(*frameBuf)
		if uint32(cap(fb.b)) >= n {
			fb.b = fb.b[:n]
			return fb.b, fb
		}
		buf := make([]byte, n)
		fb.b = buf
		return buf, fb
	}
	return make([]byte, n), nil
}

func putFrameBuf(fb *frameBuf) {
	if fb != nil && cap(fb.b) <= maxPooledFrameBytes {
		framePool.Put(fb)
	}
}

// Listen binds the unix socket (and TCP if configured). The socket directory
// is created and any stale socket file removed. If an inherited listener was
// already attached via WithInheritedListener, it is retained.
func (s *Server) Listen() error {
	if s.lnUds == nil {
		if err := os.MkdirAll(filepath.Dir(s.sockPath), 0o755); err != nil {
			return fmt.Errorf("create socket dir: %w", err)
		}
		if _, err := os.Stat(s.sockPath); err == nil {
			// Stale socket from a previous run: only remove if nothing is listening.
			if c, err := net.Dial("unix", s.sockPath); err == nil {
				c.Close()
				return fmt.Errorf("socket %s already served by a live process", s.sockPath)
			}
			os.Remove(s.sockPath)
		}
		ln, err := net.Listen("unix", s.sockPath)
		if err != nil {
			return fmt.Errorf("listen unix %s: %w", s.sockPath, err)
		}
		s.lnUds = ln
	}

	if s.tcpAddr != "" {
		tl, err := net.Listen("tcp", s.tcpAddr)
		if err != nil {
			s.lnUds.Close()
			return fmt.Errorf("listen tcp %s: %w", s.tcpAddr, err)
		}
		s.lnTcp = tl
		s.srvTcp = &http.Server{Handler: s.mux, ReadHeaderTimeout: 0}
	}
	return nil
}

// Serve runs both listeners until ctx is cancelled or SIGTERM arrives, then
// shuts down gracefully and removes the socket file.
func (s *Server) Serve(ctx context.Context) error {
	ctx, stop := signal.NotifyContext(ctx, syscall.SIGTERM, syscall.SIGINT)
	defer stop()

	s.mu.Lock()
	s.baseCtx = ctx
	s.connRoot, s.connCancel = context.WithCancel(ctx)
	connRoot := s.connRoot
	s.mu.Unlock()

	errCh := make(chan error, 2)
	go func() {
		for {
			c, err := s.lnUds.Accept()
			if err != nil {
				if s.isClosed() || isTemporary(err) {
					errCh <- nil // graceful shutdown closed the listener
					return
				}
				errCh <- fmt.Errorf("uds accept: %w", err)
				return
			}
			s.wg.Add(1)
			go func() {
				defer s.wg.Done()
				s.serveConn(connRoot, c)
			}()
		}
	}()

	var httpErrCh chan error
	if s.lnTcp != nil {
		httpErrCh = make(chan error, 1)
		go func() { httpErrCh <- s.srvTcp.Serve(s.lnTcp) }()
	}

	var runErr error
	select {
	case runErr = <-errCh:
	case runErr = <-httpErrCh:
	case <-ctx.Done():
	}
	s.shutdown()
	return runErr
}

func (s *Server) shutdown() {
	s.mu.Lock()
	if s.closed {
		s.mu.Unlock()
		return
	}
	s.closed = true
	s.mu.Unlock()
	if s.lnUds != nil {
		s.lnUds.Close()
	}
	drain := DrainTimeout()
	if s.srvTcp != nil {
		shCtx, cancel := context.WithTimeout(context.Background(), drain)
		defer cancel()
		s.srvTcp.Shutdown(shCtx)
	}
	// Await in-flight UDS connections within the same bounded drain window.
	drainDone := make(chan struct{})
	go func() {
		s.wg.Wait()
		close(drainDone)
	}()
	select {
	case <-drainDone:
	case <-time.After(drain):
		// Drain window expired: cancel remaining connection goroutines.
		s.mu.Lock()
		cancel := s.connCancel
		s.mu.Unlock()
		if cancel != nil {
			cancel()
		}
	}
	if !s.inheritedUds {
		os.Remove(s.sockPath)
	}
}

func (s *Server) isClosed() bool {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.closed
}

// serveConn speaks length-prefixed JSON over a raw UDS connection
// (membrane framing, v1). HTTP upgrades arrive via the TCP listener only.
func (s *Server) serveConn(ctx context.Context, c net.Conn) {
	defer c.Close()
	if s.metrics != nil {
		s.metrics.IncConn()
		defer s.metrics.DecConn()
	}
	if err := verifyPeerCred(c); err != nil {
		return
	}
	// Unblock any pending frame read when the connection context fires
	// (drain expiry cancels it via connCancel).
	stopWatch := make(chan struct{})
	defer close(stopWatch)
	go func() {
		select {
		case <-ctx.Done():
			c.SetReadDeadline(time.Now())
		case <-stopWatch:
		}
	}()
	cs := &connState{br: bufio.NewReader(c), bufs: make(net.Buffers, 0, 2)}
	for {
		// Tie the read deadline to the connection context deadline so an
		// idle connection never outlives the drain window.
		if dl, ok := ctx.Deadline(); ok {
			c.SetReadDeadline(dl)
		} else {
			c.SetReadDeadline(time.Time{})
		}
		fr, fb, err := readFramePooled(cs)
		if err != nil {
			return // clean EOF, framed error, or drained/cancelled connection
		}
		var resp *api.Response
		var reqID string
		var reqCtx context.Context
		reqBytes := len(fr)
		start := time.Now()
		req, derr := api.DecodeRequest(fr)
		// The raw frame payload stays live through dispatch (it is the
		// turnstile payloadBody), so it is returned to the pool only after
		// dispatch returns -- never while a reference is still held.
		if derr != nil {
			resp = api.NewErrorResponse("unknown", api.NewTransport("decode", derr, "bad envelope"))
		} else {
			reqID = req.ID
			reqCtx = logging.WithRequestID(ctx, req.ID)
			resp, _ = s.dispatch(reqCtx, req, fr)
		}
		putFrameBuf(fb)
		// Tie the write deadline to the request's effective deadline so a
		// stuck client cannot hold the connection goroutine forever.
		if reqCtx != nil {
			if dl, ok := reqCtx.Deadline(); ok {
				c.SetWriteDeadline(dl)
			}
		}
		if werr := writeFrameWithHdr(c, &cs.hdr, &cs.bufs, resp); werr != nil {
			return
		}
		c.SetWriteDeadline(time.Time{})
		dur := time.Since(start)
		s.countRequest(opOf(req, derr), "uds", resp)
		if s.metrics != nil {
			s.metrics.RecordDuration(dur)
		}
		s.logRequest(reqID, "uds", reqBytes, resp, dur)
	}
}

// dispatch applies the deadline fence, calls the handler, and stamps a 32-byte
// BLAKE3 cryptographic turnstile receipt over (op, timestampNs, payloadBody)
// on every admitted response, where payloadBody is the ORIGINAL raw request
// body (the undecoded frame payload on UDS, the undecoded HTTP body on TCP) so
// clients can verify the receipt byte-for-byte against what they sent. It
// returns the response and the receipt timestamp (unixnano) used to build it;
// HTTP callers echo the timestamp back via X-Smalt-Receipt-Timestamp so
// clients can recompute VerifyTurnstile. Request contexts derive from the
// caller's context and carry the envelope deadline via requestContext
// (context.go), so cancellation is consistent across UDS and HTTP transports.
func (s *Server) dispatch(ctx context.Context, req *api.Request, payloadBody []byte) (*api.Response, uint64) {
	ctx, cancel := requestContext(ctx, req.Deadline)
	defer cancel()
	resp := s.handler(logging.WithRequestID(ctx, req.ID), req)
	if resp == nil {
		resp = api.NewErrorResponse(req.ID, api.NewUpstream("dispatch", nil, "handler returned no response"))
	}
	// Dialect path (WO-12 inversion): when the local handler does not
	// admit the op (typed UPSTREAM refusal) and the graph-projected
	// dialect registry does, route the RAW undecoded frame payload
	// through the generated membrane adapter. The receipt is stamped
	// below over the same raw payloadBody -- Lower()/translation happen
	// inside the adapter AFTER stamping scope, and never alter the
	// receipted bytes. Adapter output is a re-encoded envelope; only
	// resp is replaced, never the turnstile input.
	if s.dialectReg != nil && s.cfg != nil &&
		resp.Error != nil && resp.Error.Code == api.CodeUpstream {
		if spec, ok := s.dialectReg.LookupOp(strings.ToLower(req.Op)); ok {
			if out, derr := adapter.Dispatch(s.cfg, spec.Op, payloadBody); derr == nil {
				if mresp, perr := api.DecodeResponse(out); perr == nil {
					resp = mresp
				} else {
					resp = api.NewErrorResponse(req.ID, api.NewUpstream("dialect", perr, "membrane adapter returned undecodable envelope"))
				}
			} else if merr, isMem := derr.(*api.MembraneError); isMem {
				resp = api.NewErrorResponse(req.ID, merr)
			} else {
				resp = api.NewErrorResponse(req.ID, api.NewUpstream("dialect", derr, "membrane dispatch failed"))
			}
		}
	}
	resp.ID = req.ID
	tsNs := uint64(time.Now().UnixNano())
	if resp.Ok != nil && resp.Receipt == "" {
		resp.Receipt = receipt.Hex(receipt.TurnstileReceipt(req.Op, tsNs, payloadBody))
	}
	return resp, tsNs
}

// logRequest emits the request lifecycle log line at debug level. At warn+
// slog's level check short-circuits before any attribute is materialized,
// keeping per-request logging off the hot path.
func (s *Server) logRequest(id, transport string, reqBytes int, resp *api.Response, dur time.Duration) {
	if !s.logger.Enabled(context.Background(), slog.LevelDebug) {
		return
	}
	respBytes := 0
	if resp != nil {
		if b, err := api.Encode(resp); err == nil {
			respBytes = len(b)
		}
	}
	attrs := []any{
		slog.String("id", id),
		slog.String("transport", transport),
		slog.Int("req_bytes", reqBytes),
		slog.Int("resp_bytes", respBytes),
		slog.Int64("duration_ms", dur.Milliseconds()),
	}
	if resp != nil && resp.Receipt != "" {
		attrs = append(attrs, slog.String("receipt", resp.Receipt))
	}
	if resp != nil && resp.Error != nil {
		attrs = append(attrs, slog.String("error_code", string(resp.Error.Code)))
	}
	s.logger.Debug("request", attrs...)
}

// handleHTTPEnvelope accepts a JSON request envelope as the HTTP body and
// answers with the JSON response envelope (used by /healthz-style probes and
// simple HTTP clients).
func (s *Server) handleHTTPEnvelope(w http.ResponseWriter, r *http.Request) {
	body, err := io.ReadAll(io.LimitReader(r.Body, MaxFrameBytes))
	if err != nil {
		http.Error(w, "read body", http.StatusBadRequest)
		return
	}
	w.Header().Set("Content-Type", "application/json")
	req, derr := api.DecodeRequest(body)
	if derr != nil {
		w.WriteHeader(http.StatusBadRequest)
		json.NewEncoder(w).Encode(api.NewErrorResponse("unknown", api.NewTransport("decode", derr, "bad envelope")))
		return
	}
	start := time.Now()
	resp, tsNs := s.dispatch(logging.WithRequestID(r.Context(), req.ID), req, body)
	if resp.Receipt != "" {
		w.Header().Set("X-Smalt-Receipt-Turnstile", resp.Receipt)
		// Echo the receipt timestamp so clients can recompute
		// receipt.VerifyTurnstile(headerHex, op, ts, rawBody) without
		// guessing the server clock sample.
		w.Header().Set("X-Smalt-Receipt-Timestamp", strconv.FormatUint(tsNs, 10))
	}
	if resp.Error != nil && resp.Error.Code == api.CodeDeadline {
		w.WriteHeader(http.StatusGatewayTimeout)
	} else if resp.Error != nil {
		w.WriteHeader(http.StatusInternalServerError)
	} else {
		w.WriteHeader(http.StatusOK)
	}
	json.NewEncoder(w).Encode(resp)
	dur := time.Since(start)
	s.countRequest(req.Op, "http", resp)
	if s.metrics != nil {
		s.metrics.RecordDuration(dur)
	}
	s.logRequest(req.ID, "http", len(body), resp, dur)
}

func readFramePooled(cs *connState) ([]byte, *frameBuf, error) {
	if _, err := io.ReadFull(cs.br, cs.hdr[:]); err != nil {
		return nil, nil, err
	}
	n := binary.BigEndian.Uint32(cs.hdr[:])
	if n == 0 || n > MaxFrameBytes {
		return nil, nil, fmt.Errorf("frame length %d out of bounds", n)
	}
	buf, fb := getFrameBuf(n)
	if _, err := io.ReadFull(cs.br, buf); err != nil {
		putFrameBuf(fb)
		return nil, nil, err
	}
	return buf, fb, nil
}

func readFrame(r *bufio.Reader) ([]byte, error) {
	var lenBuf [4]byte
	if _, err := io.ReadFull(r, lenBuf[:]); err != nil {
		return nil, err
	}
	n := binary.BigEndian.Uint32(lenBuf[:])
	if n == 0 || n > MaxFrameBytes {
		return nil, fmt.Errorf("frame length %d out of bounds", n)
	}
	buf := make([]byte, n)
	if _, err := io.ReadFull(r, buf); err != nil {
		return nil, err
	}
	return buf, nil
}

// writeFrame coalesces the 4-byte length prefix and JSON payload into a
// net.Buffers slice and invokes WriteTo(w). When w is a *net.UnixConn or
// *net.TCPConn, Go's net package dispatches through the unexported
// buffersWriter interface directly to internal/poll.FD.Writev, executing a
// single scatter-gather writev(2) syscall with zero intermediate copy
// (design.md ?7.2 Starboard Out writev conduit).
func writeFrame(w io.Writer, resp *api.Response) error {
	var hdr [4]byte
	return writeFrameWithHdr(w, &hdr, &net.Buffers{}, resp)
}

func writeFrameWithHdr(w io.Writer, hdr *[4]byte, bufs *net.Buffers, resp *api.Response) error {
	body, err := api.Encode(resp)
	if err != nil {
		return err
	}
	return writeFrameBody(w, hdr, bufs, body)
}

// writeFrameBody performs the vectored write of an ALREADY-ENCODED payload:
// the 4-byte big-endian length prefix plus body go out as one scatter-gather
// writev(2) on *net.UnixConn / *net.TCPConn. The split from writeFrameWithHdr
// exists so callers that encode once and write many times -- and the
// alloc-budget court -- can pin the write side at its floor. bufs is REBUILT
// in place per call because net.Buffers.WriteTo consumes the slice; the
// caller reuses capacity so the rebuild is allocation-free. The one residual
// allocation per call is the writev iovec scratch inside internal/poll on
// go1.23 (cached into fd.iovecs upstream in go1.24+).
func writeFrameBody(w io.Writer, hdr *[4]byte, bufs *net.Buffers, body []byte) error {
	binary.BigEndian.PutUint32(hdr[:], uint32(len(body)))
	*bufs = append((*bufs)[:0], hdr[:], body)
	_, err := (*bufs).WriteTo(w)
	return err
}

func isTemporary(err error) bool {
	return strings.Contains(err.Error(), "use of closed network connection")
}

// ReadFrame is exported for test clients reading real frames.
func ReadFrame(r *bufio.Reader) ([]byte, error) { return readFrame(r) }

    # not admission logic; the gate's subject is the shipped surface.

def scan(root):
    """Return a list of violation strings for the tree at `root`."""
    violations = []
    for rel in _elixir_files(root):
        rel_posix = os.path.relpath(rel, root).replace(os.sep, "/")
        if any(rel_posix.startswith(p) for p in F1_SANCTIONED + F2_SANCTIONED):
            continue
        try:
            text = open(rel, encoding="utf-8", errors="replace").read()
        except OSError as e:
            violations.append(f"F1/F2 unreadable {rel_posix}: {e}")
            continue
        if F1_DEFMODULE_RE.search(text):
            violations.append(
                f"F1 GraphLaw admission module outside sanctioned homes "
                f"(lib/smalt/graphlaw_ex/, lib/smalt/affidavit/, "
                f"priv/ontologies/): {rel_posix}")
        if any(rel_posix.startswith(p) for p in F2_ELIXIR_SCAN_ROOTS):
            # The sanctioned seam is the arm_gateway plug/router DELEGATING
            # to Smalt.Posh (receipt_turnstile.ex calls
            # Smalt.Posh.Egress.Settlement/EventLog). Two migrations:
            # (a) a module owning turnstile/settlement/event-log logic that
            #     does not delegate to Smalt.Posh;
            # (b) a defmodule claiming the Smalt.Posh.* namespace outside
            #     lib/smalt/posh/ -- a verbatim copy that would smuggle past
            #     the delegation clause on its own namespace.
            f2_defmodule_re = re.compile(
                r"defmodule\s+[A-Za-z0-9._]*(" + "|".join(F2_TOKENS) + ")")
            owns_logic = bool(f2_defmodule_re.search(text))
            posh_ns = bool(re.search(r"defmodule\s+Smalt\.Posh\.", text))
            delegates = "Smalt.Posh" in text
            if (owns_logic and not delegates) or posh_ns:
                violations.append(
                    f"F2 turnstile/settlement/event-log logic in arm_gateway "
                    f"(owns-logic={owns_logic}, non-delegating="
                    f"{not delegates}, posh-namespace-claim={posh_ns}; "
                    f"sanctioned seam is lib/smalt/posh/): {rel_posix}")
    # F2 posh-side settlement verbs in Go sources (decide-not-compute),
    # plus the T1/T3/T5 posh-Go detectors (same walk).
    for dirpath, _dirnames, filenames in os.walk(os.path.join(root, "posh")):
        for fn in filenames:
            if not fn.endswith(".go"):
                continue
            full = os.path.join(dirpath, fn)
            rel_posix = os.path.relpath(full, root).replace(os.sep, "/")
            try:
                text = open(full, encoding="utf-8", errors="replace").read()
            except OSError:
                continue
            for line_no, line in enumerate(text.splitlines(), 1):
                if F2_GO_VERB_RE.search(line):
                    violations.append(
                        f"F2 settlement verb in posh Go code "
                        f"({rel_posix}:{line_no}): {line.strip()[:100]}")
                    break
            # T1 clause a: store/ledger import lines.
            for line_no, line in enumerate(text.splitlines(), 1):
                if T1_STORE_IMPORT_RE.search(line):
                    violations.append(
                        f"T1 store/ledger import in posh Go (state "
                        f"ownership, F3/F4 class) ({rel_posix}:{line_no}): "
                        f"{line.strip()[:100]}")
                    break
            # T1 clause b: schema-like (Turtle) reads without a sha256 pin.
            if (T1_SCHEMA_READ_RE.search(text)
                    and not T1_PIN_RE.search(text)):
                violations.append(
                    f"T1 schema-like (.ttl) read without sha256 pin in posh "
                    f"Go ({rel_posix}): the graph is the admission "
                    f"allowlist (F4)")
            # T3/T5: write calls with persisted-ledger / .go paths.
            for line_no, line in enumerate(text.splitlines(), 1):
                if T3_WRITE_RE.search(line):
                    if T3_LEDGER_PATH_RE.search(line):
                        violations.append(
                            f"T3 persisted ledger/settlement/state write in "
                            f"posh Go ({rel_posix}:{line_no}): "
                            f"{line.strip()[:100]}")
                    if T5_GO_PATH_RE.search(line):
                        violations.append(
                            f"T5 posh-side projection write (.go) in posh "
                            f"Go ({rel_posix}:{line_no}): "
                            f"{line.strip()[:100]}")
    # F2b byte-identity pin.
    subject = os.path.join(root, F2B_SUBJECT)
    if not os.path.isfile(subject):
        violations.append(f"F2b pinned kernel missing: {F2B_SUBJECT}")
    else:
        digest = hashlib.sha256(open(subject, "rb").read()).hexdigest()
        if digest != F2B_SHA256:
            violations.append(
                f"F2b BLAKE3 kernel drifted from pinned digest "
                f"(pinned 2026-10-30, gaps/06 inheritance clause): "
                f"{F2B_SUBJECT} sha256={digest} expected={F2B_SHA256}")
    return violations

export type ResourceKind = "rg" | "kv" | "secret" | "app" | "env";

export interface TrackedArmResult {
  status: number;
  body: unknown;
  text: string;
  headers: Headers;
  /** Defined when the call was a creation (2xx PUT) and got auto-registered. */
  tracked?: TrackedResource;
}

/**
 * Bounded observable poll on the real resource. SLEEP-CLASS: POLL-STEP --
 * re-observes substrate state each attempt, fails (returns last status) at the
 * deadline; the only waits in this lib are substrate-driven LRO waits.
 */
export async function pollUntil(
  path: string,
  token: string | undefined,
  want: (status: number) => boolean,
  deadlineMs = 10_000,
): Promise<number> {
  const start = Date.now();
  let status = 0;
  while (Date.now() - start < deadlineMs) {
    const res = await arm("GET", path, undefined, token);
    if (want(res.status)) return res.status;
    status = res.status;
    await new Promise((r) => setTimeout(r, 100));
  }
  return status;
}

/**
 * arm() wrapper that auto-registers every resource created through it (2xx
 * PUT). Nested resources (secrets, apps under an rg/kv) are registered with
 * their own full ARM path so a reverse-order sweep deletes children before
 * parents without any manual bookkeeping at call sites.
 *
 * 202 PUTs are async LROs: the resource materializes LATER, so a parent
 * deleted before the child LRO lands would orphan it (witnessed: vaults
 * resurrecting after rg deletion). armTracked therefore awaits LRO completion
 * (GET -> 200) before returning for 202 creates.
 */
export async function armTracked(
  method: string,
  path: string,
  body?: unknown,
  token?: string,
  kind: ResourceKind = "rg",
): Promise<TrackedArmResult> {
  const res = await arm(method, path, body, token);
  let tracked: TrackedResource | undefined;
  if (method.toUpperCase() === "PUT" && res.status >= 200 && res.status < 300) {
    seqCounter += 1;
    const name = extractName(path);
    tracked = { kind, name, deletePath: path, seq: seqCounter };
    registry.push(tracked);
    if (res.status === 202) {
      // Await LRO so the child exists before any parent delete can run.
      const finalStatus = await pollUntil(path, token, (s) => s === 200, 10_000);
      if (finalStatus !== 200) {
        throw new Error(`LRO create did not materialize: ${path} -> HTTP ${finalStatus}`);
      }
    }
  }
  return { ...res, tracked };
}

function extractName(path: string): string {
  const segs = path.split("?")[0].split("/").filter(Boolean);
  return segs[segs.length - 1] ?? path;
}

export interface SweepReport {
  attempted: number;
  deleted: number;
  alreadyGone: number;
  failures: Array<{ name: string; status: number; text: string }>;
  /** True when sweep ran to completion despite individual delete errors. */
  completed: boolean;
}

/**
 * Delete every registered resource in REVERSE creation order. Always drains
 * the whole registry -- one failing delete never aborts the sweep (a mid-run
 * failure upstream must not leak the rest). Runs identically from afterAll
 * after a test threw.
 */
export async function sweep(token?: string): Promise<SweepReport> {
  const report: SweepReport = {
    attempted: 0,
    deleted: 0,
    alreadyGone: 0,
    failures: [],
    completed: true,
  };
  while (registry.length > 0) {
    // shift() from the front == highest-seq first == reverse creation order.
    const r = registry.pop()!;
    report.attempted += 1;
    try {
      const res = await arm("DELETE", r.deletePath, undefined, token);
      if (res.status >= 200 && res.status < 300) {
        if (res.status === 202) {
          // Async deletion: await real absence, not the 202 acceptance.
          const finalStatus = await pollUntil(r.deletePath, token, (s) => s === 404, 10_000);
          if (finalStatus !== 404) {
            report.failures.push({
              name: r.name,
              status: finalStatus,
              text: `LRO delete did not complete: ${r.deletePath} still HTTP ${finalStatus}`,
            });
            report.completed = false;
            continue;
          }
        }
        report.deleted += 1;
      } else if (res.status === 404) {
        // Already deleted (e.g. by an explicit in-suite DELETE) -- this IS the
        // goal state, not a failure.
        report.alreadyGone += 1;
      } else {
        report.failures.push({ name: r.name, status: res.status, text: res.text });
        report.completed = false;
      }
    } catch (err) {
      report.failures.push({ name: r.name, status: -1, text: String(err) });
      report.completed = false;
    }
  }
  return report;
}

function pct(samples: number[], p: number): number {
  if (samples.length === 0) return Number.NaN;
  const sorted = [...samples].sort((a, b) => a - b);
  return sorted[Math.min(sorted.length - 1, Math.ceil((p / 100) * sorted.length) - 1)];
}

function stats(b: Bench): { p50: number; p95: number; p99: number; n: number } {
  return { n: b.samples.length, p50: pct(b.samples, 50), p95: pct(b.samples, 95), p99: pct(b.samples, 99) };
}

  );
}

// HRN-009 / NFR-HERMETIC-01 -- hermetic-suite gate.
//
// Claim under test: with public egress blocked, any outbound public-cloud
// attempt fails fast and loud (typed error, bounded), never hangs. The REAL
// isolation is network-layer (egress kill switch); this suite proves the
// fail-fast behavior on top of it and statically gates app source against
// hard-coded public Azure endpoints.
//
// Chicago discipline: every runtime proof is a real OS subprocess doing a real
// fetch. No mocks.
import { execFile, spawn } from "node:child_process";
import { promisify } from "node:util";
import { fileURLToPath } from "node:url";
import path from "node:path";
import { describe, expect, it } from "vitest";

const execFileP = promisify(execFile);

const HERE = path.dirname(fileURLToPath(import.meta.url));
// apps/web/test/harness/nfr -> repo root
const REPO_ROOT = path.resolve(HERE, "../../../../..");
const GUARD = path.join(REPO_ROOT, "scripts", "hermetic_guard.sh");

const PUBLIC_ARM_URL = "https://management.azure.com/subscriptions?api-version=2022-12-01";
// Bounded deadline for the fail-fast claim itself (seconds).
const FAIL_FAST_BUDGET_MS = 5_000;

const nodeMajor = Number(process.versions.node.split(".")[0]);
// NODE_USE_ENV_PROXY landed in Node 24; without it the closed-port kill switch
// is not observed by global fetch and the runtime gate is untestable.
const PROXY_KILL_SWITCH_SUPPORTED = nodeMajor >= 24;

interface FetchOutcome {
  kind: "ok" | "typed-fail";
  detail: string;
  elapsedMs: number;
}

/** Real fetch of a public ARM URL in a child node process, bounded. */
function probePublicFetch(env: NodeJS.ProcessEnv): Promise<FetchOutcome> {
  const script = `
    const t = Date.now();
    fetch(${JSON.stringify(PUBLIC_ARM_URL)}, { signal: AbortSignal.timeout(${FAIL_FAST_BUDGET_MS}) })
      .then((r) => { console.log(JSON.stringify({ kind: "ok", status: r.status, elapsedMs: Date.now() - t })); })
      .catch((e) => {
        console.log(JSON.stringify({
          kind: "typed-fail",
          name: e.name,
          code: e.cause?.code ?? null,
          elapsedMs: Date.now() - t,
        }));
      });
  `;
  return new Promise((resolve) => {
    const child = spawn(process.execPath, ["-e", script], {
      env: { ...process.env, ...env },
      stdio: ["ignore", "pipe", "pipe"],
    });
    let out = "";
    const hardTimer = setTimeout(() => {
      child.kill("SIGKILL");
      resolve({ kind: "typed-fail", detail: "HARD-TIMEOUT-KILL (hung past budget)", elapsedMs: FAIL_FAST_BUDGET_MS + 1 });
    }, FAIL_FAST_BUDGET_MS * 2);
    child.stdout.on("data", (d) => (out += d));
    child.on("close", () => {
      clearTimeout(hardTimer);
      const line = out.trim().split("\n").findLast((l) => l.startsWith("{"));
      if (!line) {
        resolve({ kind: "typed-fail", detail: "no-output", elapsedMs: -1 });
        return;
      }
      const parsed = JSON.parse(line) as Record<string, unknown>;
      resolve(
        parsed.kind === "ok"
          ? { kind: "ok", detail: `HTTP ${parsed.status}`, elapsedMs: Number(parsed.elapsedMs) }
          : {
              kind: "typed-fail",
              detail: `${parsed.name ?? "Error"}${parsed.code ? `/${String(parsed.code)}` : ""}`,
              elapsedMs: Number(parsed.elapsedMs),
            },
      );
    });
  });
}

describe("NFR-HERMETIC-01: hermetic test isolation", () => {
  it("static gate: zero real public-Azure endpoint usages in app src + harness", async () => {
    const { stdout, stderr } = await execFileP("bash", [GUARD], { cwd: REPO_ROOT });
    expect(stderr).toBe("");
    const violations = stdout
      .split("\n")
      .filter((l) => l.startsWith("VIOLATION"));
    expect(violations, `public-endpoint violations:\n${violations.join("\n")}`).toEqual([]);
    expect(stdout).toContain("hermetic-guard: PASS");
  });

  it("runtime gate: with proxy kill-switch, public fetch fails fast and typed (never hangs)", async () => {
    if (!PROXY_KILL_SWITCH_SUPPORTED) {
      // Loud, typed SKIP -- never a silent pass.
      console.warn(
        `[SKIP] hermetic runtime gate: node ${process.versions.node} lacks NODE_USE_ENV_PROXY ` +
          `(needs >=24); egress kill-switch untestable in-process. Static gate still binding.`,
      );
      return;
    }
    const started = Date.now();
    const outcome = await probePublicFetch({
      NODE_USE_ENV_PROXY: "1",
      HTTPS_PROXY: "http://127.0.0.1:1", // closed port -> ECONNREFUSED instantly, zero external traffic
    });
    const wallMs = Date.now() - started;

    expect(outcome.kind).toBe("typed-fail");
    expect(outcome.detail).toMatch(/ECONNREFUSED|AbortError|HARD-TIMEOUT/);
    // Fail-fast: bounded wall-clock, orders of magnitude under any hang budget.
    expect(outcome.elapsedMs).toBeLessThan(FAIL_FAST_BUDGET_MS);
    expect(wallMs).toBeLessThan(FAIL_FAST_BUDGET_MS * 2);
  });

  it("control: unblocked public fetch is observed either way; isolation story is network-layer", async () => {
    // Runs BOTH ways per the order: on an internet-connected machine this
    // returns HTTP 401 (no credentials) proving reachability; on an air-gapped
    // machine it must fail typed within budget. Either outcome is admissible;
    // a HANG is not -- that is the property the bounded wrapper proves.
    const outcome = await probePublicFetch({});
    if (outcome.kind === "ok") {
      console.warn(
        `[NOTE] machine has public egress: control fetch reached management.azure.com ` +
          `(${outcome.detail} in ${outcome.elapsedMs}ms). The real hermetic isolation is ` +
          `network-layer (egress kill switch / CI job-level isolation), not app-layer -- ` +
          `see operator runbook in docs/jira/nextjs-harness/v26.10.30/receipts/.`,
      );
      expect(outcome.detail).toMatch(/HTTP \d{3}/);
    } else {
      console.warn(
        `[NOTE] machine is already egress-restricted: control fetch failed typed ` +
          `(${outcome.detail} in ${outcome.elapsedMs}ms) -- consistent with hermetic mode.`,
      );
      expect(outcome.detail).not.toBe("no-output");
    }
  }, FAIL_FAST_BUDGET_MS * 2 + 1_000);
});
