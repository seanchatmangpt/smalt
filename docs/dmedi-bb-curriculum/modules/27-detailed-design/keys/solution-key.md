## Receipt B — verification study derivation (verbatim script + output)

import csv, statistics as st, math
rows = list(csv.DictReader(open('data/thermal-warmup-study.csv')))
a = [float(r['bore_deviation_um_no_model']) for r in rows]
b = [float(r['bore_deviation_um_with_model']) for r in rows]
print('n', len(rows))
print('no-model mean', round(st.mean(a), 2), 'sd', round(st.stdev(a), 2),
      'min', min(a), 'max', max(a))
print('with-model mean', round(st.mean(b), 2), 'sd', round(st.stdev(b), 2),
      'min', min(b), 'max', max(b))
print('mean reduction um', round(st.mean(a) - st.mean(b), 2),
      'ratio', round(st.mean(a) / st.mean(b), 2))
print('trials >3um with model:', [(i + 1, v) for i, v in enumerate(b) if v > 3])
print('trials >3um no model:', sum(1 for v in a if v > 3))
d = [x - y for x, y in zip(a, b)]
dbar = st.mean(d); sd = st.stdev(d); se = sd / math.sqrt(len(d))
print('paired d-bar', round(dbar, 2), 'sd_d', round(sd, 2),
      't', round(dbar / se, 2))
print('95% CI (t975=2.201 x se):', round(dbar - 2.201 * se, 2),
      'to', round(dbar + 2.201 * se, 2))

## Keyed answers

1. sigma_max = 0.008/(3 x 1.33) = 0.008/3.99 = 0.002005 mm = **2.01 um**
   (court prints 2.0 at 1 dp). Baseline guard-band Cpk at the adjudicated
   spine sigma: 0.008/(3 x 0.007407) = **0.36** (court-verified). Note the
   court also carries the historical 4.17 um regime (guard Cpk 0.64) — cite
   the spine (0.36) in any current document.
2. Factor in sigma = 7.407/2.005 = **3.69x**; variance factor = 3.69^2 =
   **13.6x**. Variance composes because independent error sources ADD in
   variance (sigma_total^2 = sum of sigma_i^2): three independent variance
   halvings give 0.5 x 0.5 x 0.5 = 0.125 of the original variance (2.83x
   sigma), and the court's 13.6x decomposes the same way — a 3.69x sigma
   target is not reached by "3.69 divided among a few fixes"; it is reached
   by multiplying variance fractions, which is why the DOE finds the big
   terms first.
3. No-model: mean **9.34 um**, sd **1.57 um** (12/12 trials > 3 um).
   With-model: mean **2.14 um**, sd **1.44 um**; reduction **7.20 um**
   (4.36x); breaches: trial 6 (4.8 um), trials 7 and 12 (3.4 um each);
   paired d-bar 7.20, t = 12.8, 95% CI [5.96, 8.44] — the reduction is real.
   Verdicts: mean-based reading = PASS (2.14 <= 3); per-piece reading =
   **FAIL** (3 of 12 first-pieces exceed 3 um). The CP-13 criterion says
   "first-piece deviation <= 3 um" — a per-piece bound — so the honest
   verdict is **FAIL as specified**: the model works but the warmup duration
   before activation is underspecified. Lawful next action: extend warmup or
   re-issue the criterion with rationale, then re-verify.
4. CP-1 measurement (in-process gauge + AE trip), CP-8 poka-yoke
   (error-proofing), CP-10 design change (DFA — the chamfer), CP-13 process
   control (DFT — thermal model), CP-15 measurement (refractometer check).
   Shared error-proofing pattern: all three error-proofing rows (CP-5, CP-8,
   CP-16) are INTERLOCKS — the control physically refuses the bad state
   (wrong offset entry, misloaded part, wrong program) rather than detecting
   it afterwards, and each acceptance criterion is a seeded-defect trial with
   a 100% refusal rate.
5. CP-3 verifies DC-02b (gauge R&R) and is operationalized by Module 11
   (MSA; acceptance feeds Module 12 capability). CP-13 verifies DC-10 (thermal
