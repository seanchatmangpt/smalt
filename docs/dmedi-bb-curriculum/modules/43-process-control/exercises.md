# Module 43 Exercises

1. **Limit arithmetic.** For n = 5: given X-double-bar = 12.0049 and R-bar = 0.0102, compute UCL/LCL(X-bar) and UCL(R). Then recompute with n = 4 constants (A2 = 0.729, D4 = 2.282) and explain which constants change and why.
2. **Limits vs specs.** A teammate proposes widening the control limits to the spec limits "so the operator has room". Give the two-line rebuttal using sigma-hat and PCR from the lab.
3. **DFMEA linkage.** Write the missing linkage: failure mode "bore oversize from tool wear" → detection control → chart → reaction. Then invert: name a control plan row you would DELETE because its DFMEA row was removed.
4. **p-chart signal.** With p-bar = 5/4500 and n = 150, compute UCL/LCL and decide whether day 1 (3 scrap) signals. What changes if the subgroup size varies day to day (80–120 pieces)?
5. **OCAP ordering.** Rearrange these actions into lawful OCAP order and justify: adjust compensation; quarantine parts since last in-control subgroup; log entry; verify with 3 consecutive in-control subgroups; diagnose tool wear vs thermal drift.
6. **Vacuity test.** Design the one-sentence check a week-26 auditor runs on a control plan row to prove it is not decoration.
