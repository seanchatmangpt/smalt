# Module 34 Exercises

1. **Development takt.** The program consumes 92 work-days of content in 130 calendar days.
   If demand is "one gate package per phase," what is the decision takt (days per decision)
   at baseline vs scenario F? Which cadence matches a weekly program review?
2. **WIP limit arithmetic.** Explore phase has 6 work packages, each 5 days of content, done
   serially with 0.5 d average dependency wait each. Compute phase duration. Under a
   3-package WIP limit with 2 people, model duration assuming perfect parallelism within WIP.
   State your modeling assumption and its risk.
3. **Rework loop cost.** A failed Develop gate re-opens 30% of the phase's work (21 x 0.3 = 6.3
   work-days) plus a second gate wait. Compute expected phase duration if gate pass probability
   is 0.7 (first pass). Compare with pre-gate peer review that costs 2 work-days and raises
   first-pass to 0.9.
4. **Little's Law on the gate queue.** If gate packages arrive on average every 4 working days
   and wait 3 days, how many packages are waiting on average? What arrival rate makes a
   1-day decision SLA unstable (queue grows)? Name the utilization threshold.
