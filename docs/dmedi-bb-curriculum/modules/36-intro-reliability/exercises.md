# Module 36 Exercises

1. **Shape reading.** Three hazard plots: (a) hazard falls from 0.02/h toward 0; (b) hazard
   flat at 0.000833/h; (c) hazard ~0 for 500 h then rises steeply. Assign each a Weibull beta
   regime and name a plausible CPPC component for each.
2. **Parallel math.** A spindle assembly has availability 0.9962 (worked problem). The shop
   buys a second, fully independent spindle line for the same operation and switches on
   failure (perfect switch). Compute system availability. Is the purchase justified vs the
   33 h/year downtime figure at $150/h lost margin?
3. **B10 allocation.** The assembly B10 target is 900 h. Under the exponential assumption each
   component would need B10_i such that... show that exponential B10s do NOT sum the way
   lambdas do, and state what must be allocated instead (lambda or eta+beta pairs).
4. **Censored data.** 38 of 40 units failed; 2 units were removed from test at 1500 h
   unfailed. Explain in 3 sentences why computing "mean of failure times of the 38" overstates
   or understates MTBF, and name the estimator that handles this (no computation required).
5. **Spine audit.** A vendor datasheet claims "MTBF 1200 h, B10 900 h, exponential."
   Write the two-line refutation using Slide 2's identity, with the exponential B10 number.
