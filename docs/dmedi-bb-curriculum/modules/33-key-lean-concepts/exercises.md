# Module 33 Exercises

Answer with derivations; the solution key shows the work, not just answers.

1. **Takt under demand shift.** Demand rises to 300 housings/day (same calendar). Derive the new
   takt and the required mill count. Does any other step cross takt?
2. **Waste audit.** For each of the 7 wastes, name the stream step where it lives and the CSV
   column/row evidence. Two wastes are NOT directly visible as a column — which two, and what
   data would you collect?
3. **Queue math.** Using Little's Law (L = lambda x W), the mill queue holds 2.6 days of WIP.
   With throughput 129 housings/day (single mill), how many housings sit in the mill queue on
   average? If W is cut to 1.0 day, what queue count does the same throughput imply?
4. **Inspection double-verify.** Op20 in-process bore checks + Op50 CMM verify the same CTQ-1.
   Write the argument for and against eliminating Op50 CMM given the baseline Cpk of 0.72.
   What baseline capability would make elimination defensible?
5. **PCE interpretation.** A consultant claims cutting lead time 18.4 -> 7 d requires 61% more
   machine capacity. Refute or confirm with the PCE decomposition.
