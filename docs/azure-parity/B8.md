# B8 TlsBlobDispatchTest 404

Standing: PASS-PENDING-COORDINATOR-RERUN (UNVERIFIED until rerun; lane cannot run mix)

Root cause: test created the container with a bare `PUT /{acct}/{cont}` (no restype). Per
storage_catch_all.ex queue_plane_route("PUT",[account,queue]) a restype-less, comp-less PUT is
Queue Create, so a queue was made and the later blob PUT got ContainerNotFound 404. Real Azure
Create Container requires `restype=container`; the test premise was wrong, dispatch is correct.
Fix: test now PUTs `?restype=container`. Source unchanged.

Rerun: mix test test/integration/tls_blob_dispatch_test.exs
