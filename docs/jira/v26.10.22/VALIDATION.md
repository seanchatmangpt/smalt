## 1. Method

- Standing vocabulary: ALIVE / PASS / PARTIAL_ALIVE / UNSUPPORTED / CLOSED /
  UNKNOWN / UNWITNESSED / PENDING. A receipt with no standing line is
  UNWITNESSED; commit messages are evidence-of-activity, never standing.
- Standing is re-read from the receipt file's own standing line at fold time.
- A cell may only flip on its own receipt; a fold never smooths a standing.
- Falsifier: any receipt path cited here failing `[ -f ]`, or a standing line
  on disk disagreeing with the cell typed here, reopens this board.
