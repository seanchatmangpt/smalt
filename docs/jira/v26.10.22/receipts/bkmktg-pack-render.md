## Rendered-vs-handwritten diff (typed)

Pack template v0.2.0 renders **Deployment + one single-port Service** only.
Everything else is a typed divergence, hand-written stays deployable:

1. **Kind**: backend is a StatefulSet in `k8s/smalt-backend.yaml`; rendered is a Deployment — loses `serviceName`, OrderedReady pod management, per-pod DNS (`smalt-backend-N.smalt-backend-headless…`) that `RELEASE_NODE` depends on. **Hard gap** (pack backlog: NetworkPolicy/RBAC/PDB etc., and StatefulSet is not even on the disclosed backlog).
2. **Services**: hand-written carries 3 backend Services (headless `clusterIP: None`, ClusterIP with 4 ports, NodePort with 4 fixed nodePorts); template renders exactly one Service with one port. Rendered backend Service (9443 ClusterIP) is a subset of the real client-facing one; headless + NodePort unmodelable.
3. **Ports**: 7 container ports in hand-written (9443/9444/8443/5672/5673/4369/9000); template has one `containerPort`. Rendered carries 9443 only.
4. **Env**: template has `envFrom` only. `RELEASE_NODE`/`POD_NAME` (fieldRef) /`RELEASE_COOKIE` (secretKeyRef) and console `NEXT_PUBLIC_SMALT_ARM/EGRESS` are **unrenderable** — the rendered manifests would boot a broken swarm (no dist node name). Presence shim: `k8s:envFromSecret ""` bound to both containers because strict Tera refuses a missing GROUP_CONCAT `c.secrets` key; renders nothing (loop `if sec` guard), commented in the .ttl.
5. **nodePort 30080** (console) unmodelable — rendered NodePort Service gets an allocated port.
6. **Volumes**: backend tmpfs `/tmp` + `smalt-tls` Secret mount, affinity, `terminationGracePeriodSeconds` — all unmodelable.
7. **Gate-checked hardening the renders DO carry (parity with hand-written, now gate-enforced)**: pod+container securityContext (runAsNonRoot 65534/fsGroup, allowPrivilegeEscalation:false, readOnlyRootFilesystem, drop ALL), resource requests/limits (500m/512Mi → 2/2Gi; 100m/256Mi → 500m/512Mi), readiness/liveness probes, envFrom ConfigMap.

**Verdict**: hand-written manifests remain the deployable set; the `.gen.yaml` files are the gate-checked reference proving the fact graph is the hardening source of truth. Replace only when the pack models StatefulSet + multi-port + env/volumes.
