## Real-Azure semantics cited

Microsoft.ServiceBus `namespaces create or update` (PUT) is a long-running
operation: real Azure answers **202 Accepted** with `Azure-AsyncOperation`,
`Location` and `Retry-After` headers and an AsyncOperationStatus body to
poll until `Succeeded`. Sources: Microsoft Learn REST reference,
[Namespaces — Create Or Update (Azure Service Bus)](https://learn.microsoft.com/en-us/rest/api/servicebus/controlplane/namespaces/create-or-update?view=rest-servicebus-controlplane-2026-01-01)
(and the CLI reference noting `az servicebus namespace create` is async).

The substrate answers the same: 202 + both LRO poll headers + Retry-After +
InProgress→terminal operation resource, then a 200 resource GET. The w32
typing compared the substrate against a naive *sync* reading (200/201) of
the Azure face; real Azure is async here. The 202 is parity, not divergence.
