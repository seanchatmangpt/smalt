## 1. Template + query change

### What AdmitsHost expects (read first, per lane contract)

`posh/internal/egress/egress.go:38-58` — `NormalizeHost` strips scheme
(`url.Parse`), strips port (`net.SplitHostPort`), unwraps `[v6]`, lowercases.
`AdmitsHost` normalizes BOTH the requested host and every yaml entry before
the string compare. `config.go:84-99 validate()` rejects any yaml entry
containing `/: @` (scheme, port, path, space). Consequence: the yaml wants a
**bare lowercase hostname**; `http://127.0.0.1:9443` must project to
`127.0.0.1`. Port is discarded by NormalizeHost, so two sinks
`127.0.0.1:7443` and `127.0.0.1:9443` collapse to one entry `127.0.0.1`
(SPARK: DISTINCT + ORDER BY handles the collapse deterministically).

### Query diff (extend construct_go_adapter.rq — or add a sibling SELECT)

SPARQL 1.1 `LCASE`/`REPLACE` express the exact NormalizeHost pipeline for the
shapes the graph actually carries (http/https URLs). Keep the existing
solution rows untouched; add:

```sparql
# --- egress_allowlist projection (GAP-29): graph -> bare hostname --------
# Normalization mirrors egress.NormalizeHost: strip scheme, strip port,
# lowercase. Config validation rejects any entry still containing / : @ or
# a space, so a value that survives REPLACE with one of those chars is a
# graph defect and must fail generation loudly (see template guard).
SELECT DISTINCT ?egressHost WHERE {
  ?sink a posh:Sink ;
        posh:deliverTo ?raw .
  BIND(LCASE(REPLACE(
         REPLACE(?raw, "^[a-z][a-z0-9+.-]*://", ""),   # strip scheme
         ":[0-9]+(/.*)?$", "")) AS ?egressHost)          # strip port+path
}
ORDER BY ?egressHost
```

The port+path strip pattern also removes any residual path, so a graph value
like `http://h/p` normalizes to `h`; the remaining-char guard below is the
belt to that braces.

### Merge law (fail-closed precedence)

- **Graph = ceiling.** Effective allowlist ⊆ graph-projected set. The
  operator posh.yaml may NARROW (delete entries), never widen.
- Runtime authority stays posh.yaml (config.go/egress.go untouched) — the
  generated fragment is not read at runtime.
- Integration check in the recipe: every entry in committed `posh/posh.yaml`
  `egress_allowlist` must be a member of the generated set; an operator entry
  outside the ceiling fails the check (exit 1), naming the entry. This keeps
  "flip the yaml" actions graph-consistent — closing the GAP-16 verdict's
  "no graph-consistency court for a yaml flip" exposure.

## 2. posh-regen-check recipe

New recipe in `justfile.d/58-posh.just` (per-lane module import law,
same-checkout-fanout §5), sibling of posh-court's POSH-GENERATE stage:

```
# posh-regen-check: regen -> normalize -> byte-compare -> exit 1 on drift.
# Fail-closed: any drift, vacuous render, or ceiling violation is exit 1.
posh-regen-check:
    #!/usr/bin/env bash
    set -euo pipefail
    PACK=${SMALT_POSH_PACK:-ggen-marketplace/packs/posh}
    # 1. Regenerate into the pack's generated/ tree (same command the court
    #    uses, so the check exercises the real pipeline).
    sync_out=$(cd "$PACK" && ggen sync run --format json 2>/dev/null) \
      || { echo "[REGEN-CHECK-FAIL] ggen sync run failed" >&2; exit 1; }
    rows=$(printf '%s' "$sync_out" | python3 -c \
      'import sys,json; d=json.load(sys.stdin); print(len(d.get("written",[]))+len(d.get("skipped",[])))')
    [ "$rows" -gt 0 ] || { echo "[REGEN-CHECK-FAIL] 0 render rows (vacuous)" >&2; exit 1; }

    # 2. Normalize formatting identically on both sides before byte-compare.
    #    (Witnessed drift class: gofmt-only diffs. gofmt BOTH trees, else
    #    the gate is a formatting gate, not a content gate.)
    gofmt -w "$PACK/generated/posh/internal/adapter/"*.go posh/internal/adapter/*.go

    # 3. Merge the egress fragment: copy-out Go, then merge-check yaml.
    cp "$PACK"/generated/posh/internal/adapter/*.go posh/internal/adapter/
    python3 scripts/posh_merge_egress.py \
      --fragment "$PACK/generated/posh/config/egress_allowlist.generated.yaml" \
      --config posh/posh.yaml || exit 1

    # 4. Byte-compare regenerated vs committed (the gate proper).
    if ! diff -r "$PACK/generated/posh" posh/ ; then
      echo "[REGEN-CHECK-FAIL] regenerated tree drifts from committed" >&2
      exit 1
    fi
    echo "[REGEN-CHECK] PASS: generated == committed, allowlist within graph ceiling"
```

(`scripts/posh_merge_egress.py` — hand-written residue: reads fragment,
validates no `/:@ ` chars, asserts committed posh.yaml entries ⊆ fragment,
rewrites the generated block between `# BEGIN/END GENERATED-EGRESS` markers
in posh.yaml preserving operator lines outside the block. Exit 1 with the
offending entry on any violation.)

Note the step-4 diff target: because the fragment lands under
`generated/posh/config/` and posh.yaml is integrated at `posh/posh.yaml`, the
merge script writes the integrated yaml to a temp and the diff compares
`generated/posh` vs `posh/` with the fragment path mapped. Implementation
detail at land time; the gate is "regenerated bytes == committed bytes after
one canonical normalization pass (gofmt), zero diff".
