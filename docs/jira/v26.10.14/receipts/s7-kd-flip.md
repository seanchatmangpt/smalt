### kd_flip.py

- Scans `lib/` + `workspace/lib` (+ repeatable `--scan-root`) for
  `# KD-COVERS:` / `// KD-COVERS:` comment tokens in .ex/.exs/.js/.mjs/.cjs/
  .ts/.py files; builds a covers-map KD id -> {file: newest mtime}.
- For each OPEN KD row in the covers-map: witness = the row's evidence
  column (col 4) paths plus any file under `receipts/` or `sdk-results/`
  mentioning the id; FLIP-ELIGIBLE iff some witness has mtime AFTER the
  newest shim file's mtime and shows a PASS verdict (no FAIL/DIVERGENCE
  table row naming the id). Otherwise FLIP-PENDING-WITNESS.
- `--apply` rewrites the status cell OPEN -> `CLOSED-SIMULATED (shim landed,
  witness receipt at <path>)` ONLY for FLIP-ELIGIBLE rows. Refused outright
  if any KD-COVERS token names an id missing from the register (exit 1,
  register-sync gate). Read-only by default.
- Zero rows flipped by this lane. The tool never judges code; it only reads
  witness artifacts on disk.

### sdk_coverage.py extension

- `load_kd` now carries each row's status; a coverage cell whose KD rows are
  ALL CLOSED-SIMULATED renders `SIM-PASS` (distinct from PASS — simulated,
  not native) instead of REGISTERED-DIVERGENCE. SIM-PASS adds no finding and
  is printed in the summary as "counts as covered".
