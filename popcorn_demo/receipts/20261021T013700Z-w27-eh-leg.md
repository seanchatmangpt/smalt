## What was built

**Event Hubs enterprise leg over the real AMQP 1.0 wire.** Recon finding:
lib/smalt has NO HTTP/REST face for Event Hubs — the 5673 plane is the
`Smalt.Amqp` listener with `Smalt.Messaging.EventHubs` ETS storage behind it
(`grep -rl event_hubs lib/smalt` → `messaging/event_hubs.ex`,
`messaging/amqp/connection.ex` routes `/eventhubs/...` attach addresses). So
the HTTP-seam branch was void and the AMQP branch was taken.

`PopcornDemo.LiveEh.run/0` is a self-contained minimal AMQP 1.0 client
(popcorn_demo has no dep on smalt) over a real `:gen_tcp` socket:

1. SASL ANONYMOUS handshake (server offers `[ANONYMOUS]`; sasl-outcome
   arrives with the 0x44 descriptor wire pinion — code 0 arrives as the
   uint0 fast constructor 0x43 on this broker).
2. AMQP open/begin; sender attach to `/eventhubs/popcorn-eh/partitions/0`
   (the fixed-partition wire pinion `["0","1"]` respected — partition "0").
3. Unsettled transfer of a unique `w27-evt-<ms>` token; broker settles with
   `accepted` (0x24 descriptor, scanned in the disposition list bytes).
4. Receiver attach on the SAME partition, flow credit 100, deliveries
   scanned (delivery+message annotations present before the data section —
   the body_data 0x75 marker is scanned anywhere in the payload, mirroring
   `Smalt.Amqp.Connection.eh_body_section_scan/1`) until the token bytes
   come back byte-exact.

Receipt contract honored: `{:ok, "eh=OK(...)"} | {:skip, "eh=SKIP(...)"} |
{:error, "eh=FAIL(step:reason)"}`. Chicago school: only collaborators are the
live substrate and the wire; no mocks anywhere in the module or test.

## Defects found and fixed while landing the leg (all in this lane's file)

The hand-rolled codec surfaced four real wire findings, each witnessed by a
trace against the live broker:

1. Frame size precedence: `<<8 + body_bytes::32, ...>>` binds `::32` to
   `body_bytes` only — declared frame sizes were 8 bytes short, the broker
   held the connection open waiting for bytes that never came (presented as
   recv timeouts). Fix: `(8 + body_bytes)::32`.
2. list8 size must INCLUDE the count octet (spec §1.6.12, mirrors
   PrimitiveCodec `body_len + 1`); emitting `payload` alone desynced every
   composite and the broker read a 1-byte-short performative.
3. sasl-outcome code 0 arrives as the uint0 fast constructor `0x43`, not
   ubyte `0x50 0x00` — a decoder pinned to one encoding misreads a successful
   handshake as code_not_zero.
4. EH deliveries prefix delivery+message annotations before the body_data
   section; a prefix match on `0x00 0x53 0x75` never matches. Scan, don't
   prefix-match (mirrors `eh_body_section_scan/1`).
