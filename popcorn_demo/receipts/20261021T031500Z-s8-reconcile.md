## What landed

`PopcornDemo.Reconcile` on real seams, zero mocks:

- `stage/2` — stages local mutations into real named ETS (`:reconcile_store`),
  validates string `id` + monotonic integer `_v`, returns `{hash, staged}`.
  WORM flag carried per doc via `worm: true`.
- `reconcile/2` — the "reconnect" merge, monotonic rules only:
  - higher `_v` wins (either side)
  - equal `_v` + identical bytes → `:converged`
  - equal `_v` + divergent bytes → typed conflict
    `:equal_version_divergent_bytes` with id/_v/local/remote; NOTHING overwritten
  - WORM ids: any lower-`_v` overwrite refused `:worm_monotonicity`
    (higher-`_v` remote still merges — monotonic, not frozen)
  - merge winners are persisted back to the ETS store; the result hash is
    recomputed post-merge
- `consistency_hash/0` — sha256 (`:crypto`) over sorted `{id, _v}` tuples.

Sub-Turing: single bounded pass over a sorted enumerable per reconcile;
no sleeps, no spawn, no waits (sleep-gate clean by inspection: zero
`Process.sleep` in either file).
