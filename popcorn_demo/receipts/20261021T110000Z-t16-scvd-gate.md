# T16 — SCVD fragment gate wired into browser smoke (writer)

Standing: ALIVE

Context: pair

## What

`popcorn_demo/scripts/browser_smoke.mjs` now carries a fail-closed SCVD gate:
after the existing exit-code computation, it parses the `scvd=` fragment from
SMOKE_RECEIPT and forces exit 1 with a typed reason on:

- `SCVD-FRAGMENT-MISSING` — no `scvd=` in the receipt
- `SCVD-FRAGMENT-MALFORMED` — fragment present but not `scvd=(OK|SKIP|FAIL)(...)` or no `t16:<n>ms` wall
- `SCVD-BASELINE-MISSING` — `tmp/bench/scvd-wasm-vs-host.jsonl` absent
- `SCVD-DEGRADED` — `scvd=SKIP/FAIL(...)` or t16 wall > 3x the rolling-best
  t16 parsed from the `scvd=OK(t16:` rows of the baseline jsonl

The existing `live=SKIP` exit-3 path is computed first and `finalExit === 3`
is preserved — the gate never upgrades a 3 to a pass. cosmos_sql / sb_rule /
registry / live legs unchanged (their contracts ride the unchanged exit-code
IIFE).
